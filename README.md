# Antenna Theory, Radar, and DSP Portfolio

Graduate antenna theory portfolio linking electromagnetic fundamentals to radar, MIMO, DOA estimation, beamforming, DSP, and FPGA-based signal processing.

This repository contains my personal study notes, derivations, and numerical examples.
simulation scripts, and presentation materials for **EE 6530 Antenna Theory**.

The work is organized chapter by chapter and is primarily based on my study of:

> Warren L. Stutzman and Gary A. Thiele,  
> *Antenna Theory and Design*, 3rd Edition,  
> John Wiley & Sons, 2013.

The purpose of this repository is to build a rigorous engineering portfolio in antenna design
theory and connect the course material to practical topics such as radar systems,
MIMO radar, direction-of-arrival estimation, beamforming, RF front-end modeling,
DSP and FPGA-based signal processing.

---

## Repository Purpose

This repository is intended for:

- Personal study and review
- Graduate-level antenna theory learning
- Original derivations and numerical examples
- MATLAB/Python-based antenna simulations
- Lecture-style summaries and presentations
- Connecting antenna physics to radar, MIMO, DOA estimation, and DSP systems

This is **not** an official solution manual and is not affiliated with the textbook authors,
publisher, or Kennesaw State University.
