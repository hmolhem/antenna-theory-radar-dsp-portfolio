# Chapter 2 — Antenna Fundamentals

This folder contains the Chapter 2 materials for the antenna theory, radar, and DSP study portfolio.

Chapter 2 develops the mathematical and engineering foundations of antenna analysis. It connects Maxwell's equations, current distributions, vector potentials, radiated fields, radiation patterns, directivity, gain, impedance, radiation efficiency, and polarization.

## Main Topics

- Time-harmonic Maxwell equations
- Phasor representation of electromagnetic fields
- Poynting vector and radiated power
- Magnetic vector potential formulation
- Far-field approximation
- Ideal dipole radiation
- Near-field and far-field regions
- Radiation patterns and half-power beamwidth
- Radiation from line currents
- Element factor and pattern factor
- Directivity and gain
- Antenna input impedance
- Radiation resistance
- Radiation efficiency
- Linear, circular, and elliptical polarization
- Polarization mismatch
- Connections to radar, MIMO, DOA estimation, beamforming, DSP, and FPGA-based signal processing

## Engineering Focus

The main engineering idea of this chapter is the following chain:

**Current distribution**  
→ **Vector potential**  
→ **Radiated electric and magnetic fields**  
→ **Radiation pattern, directivity, gain, impedance, efficiency, and polarization**  
→ **Radar, MIMO, DOA, and DSP system performance**

This chapter is especially important for understanding how the physical antenna layer affects received signal amplitude, phase, array manifold modeling, covariance-matrix formation, beamforming, and direction-of-arrival estimation.
